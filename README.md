# ⚔️ 스쿨히어로 (School Hero)

서울 지형을 모티프로 한 **판타지 3D 액션 RPG** 1단계입니다.
졸업식 날 차원이동을 당한 고등학생이 서울 판타지 세계를 돌며 강해져 지구로 돌아가는 이야기입니다.

- 정적 파일만으로 동작합니다 (빌드 없음). `index.html`을 열면 바로 시작합니다.
- 3D는 Three.js r160(로컬 번들, MIT)을 사용하고, 불러오지 못하면 CDN으로 대체합니다.

## 1단계 콘텐츠

| 구분 | 내용 |
| --- | --- |
| 구역 | 여의도 시작의 숲 · 마곡 안개 늪지 · 강북 황금 사막 · 한강 심해 유적 (2단계 5구역은 지도에 예고) |
| 몬스터 | 구역별 일반·정예 + 중간보스 + 구역 보스, 원거리/독/장판 패턴 |
| 무기 | 검·단검·도끼·둔기·활·석궁·지팡이·마법책 8종 (계열별 공격력 공식과 고유 특성) |
| 장비 | 6등급(일반→신화), 방어구 4종(참격·타격·원거리·마법 저항), 악세서리 3종(목걸이·반지·귀걸이) |
| 성장 | 힘·민첩·체력·지력, 레벨업 스탯 투자, 3개 합성 승급, 영혼 4종 특성보드, 동료 3인 |
| 시스템 | 구역 메달(피해·방어 최대 +70%), 숨겨진 보관함 13개, 퀘스트 NPC, 수중호흡 아티팩트 입장 제한 |
| 화면 | 하이 탑다운 3D, 하단 조이스틱(WASD/방향키), 우측 상단 원형 미니맵 → 서울 전체 월드맵 |

## 조작

- 이동: 화면 하단 조이스틱 또는 PC의 `WASD` / 방향키
- 공격: 사거리 안에 적이 들어오면 자동 공격 (무기별 방식)
- 미니맵을 누르면 전체 지도, 메달 배지를 누르면 구역 정보가 열립니다.

## 저장 · 계정

- 게임은 저장 창구(`SaveAdapter`)만 호출하고, 저장소를 직접 알지 않습니다.
- 로그인하면 계정별로 암호화되어 저장되고, 같은 아이디로 다시 들어오면 이어서 합니다. 게스트는 이 기기에만 저장됩니다.
- 저장본에는 `saveVersion`, `updatedAt`, `HMAC-SHA256` 서명이 함께 기록됩니다.
- 불러올 때 로컬 캐시와 원격 저장본의 버전을 대조하고, 서명이 맞지 않거나 정상 범위를 넘는 수치(레벨·골드·장비 수 등)가 감지되면 변조로 판단해 마지막 정상본으로 복구합니다.
- 가족 연결 코드는 시작 화면의 **설정 → 계정**에서 넣을 수 있습니다.

## 검증

- PC 1280×800 / 모바일 390×844에서 3D 렌더·이동·자동 공격·미니맵·월드맵·상자·합성·스탯·특성·동료·퀘스트·입장 제한·메달·설정 편집·계정 저장/변조 복구를 자동 테스트로 확인했습니다.

## 3차 개편 — 2.5D 도트 · 13건 수정 · 보상/진화/외형

### 그래픽
- **2.5D 도트 전환**: 주인공은 카메라 각도에 맞춘 **탑뷰 도트 스프라이트**(머리·어깨·망토·무기가 위에서 보이고, 이동·공격 방향으로 회전), 몬스터는 **카메라 정면 빌보드 도트 스프라이트**(NearestFilter)로 교체했습니다. 바닥 그림자 원반과 통통 튀는 스쿼시·피격 플래시가 들어갑니다.
- **슬라임 리모델링**: 눈알 튀어나온 구형 대신 키세스 초콜릿(물방울) 모양으로 그렸고, 고블린·오크·오우거·엔트·해골 계열·히드라·마녀·크라켄 등 20종을 개성 있게 다시 그렸습니다.
- **초상화**: 시작 화면·캐릭터 선택·HUD 초상화를 캔버스로 그린 고해상도 얼굴 초상화로 교체하고, 인게임 도트 캐릭터의 배색과 맞췄습니다.

### 13건 수정
1. 모바일 확대·고정 차단: viewport, 16px 입력칸, 핀치·더블탭 차단, `touch-action`.
2. 새로고침 세션 유지: `sh.session`(계정·게스트)로 로그인 창 없이 자동 복구.
3. 로그인 → **캐릭터 선택** → 졸업식 인트로 → 시작 가이드 순서 정리(기존 진행 계정 포함). 이름 입력칸 추가(`state.heroName`).
4. 시작 가이드를 슬림 배너로 줄이고 조이스틱·메뉴와 겹치지 않게 재배치, 스킬바 재렌더로 인한 터치 끊김 수정.
5. 무기 8종 공격 연출 개선(검 잔상·단검 연격·도끼 파편·둔기 충격·활/석궁 머즐 플래시·지팡이 마법진·마법책 페이지).
6. 숨겨진 상자를 자동으로 열지 않고 **[📦 열기]** 버튼을 눌러 열도록 변경(금화 연출·보상 토스트).
7. 퀘스트 `보상 받기` 무응답 수정: 보상 결과를 대화창 안에 표시하고 토스트를 모달 위로 올림.
8. 중간보스 몸체·이름표 분리 수정(보스 AI가 이동한 뒤 메시 위치를 갱신하지 않던 버그).
9. 적 스킬 빨간 원을 지형 위로 띄우고 `depthTest:false` + `renderOrder`로 항상 보이게, 쿨다운·텔레그래프 빈도 완화.
10. 보스 리스폰: 중간보스 4시간 · 에픽보스 6시간 · 지역 필드보스 24시간. 타이머를 저장하고 구역 정보에 남은 시간을 표시(관리자 테스트 초기화 지원).
11. 등급별 보상 개편(일반: 경험치+일반 영혼 / 정예: 녹색 장비 / 중간보스: 파란 영혼+파란 장비 / 에픽보스: 보라 영혼+보라 장비 / 지역 보스: 지역 보스 영혼+노란 장비)과 **개수 기반 빨강(신화) 진화**(300·200·100·70·30).
12. 몬스터 전체 도트 리모델링(20종).
13. 주인공 4종 아바타 도트·초상화 교체.

### 추가 개편
- **장비 외형 반영**: 장착 무기(8종·등급 색)와 방어구(경갑·중갑·판금·로브)가 인게임 탑뷰 캐릭터와 가방 미리보기에 실시간 반영됩니다.
- **가방 통합**: 하단은 스킬 퀵슬롯 + `🎒 가방`만 두고, 가방 시트 안에 가방·합성·특성·스탯·스킬·동료·설정(관리자만)·도움말 탭과 캐릭터 미리보기·핵심 스탯·재화를 모았습니다.
- **외형(코스튬)**: 장착 방어구 / 기본 교복 / 코스튬 중 선택. 코스튬은 `🎲 외형 뽑기`(120골드, 중복 60골드 환급)로 해금하고, 보유 코스튬마다 수집 보너스 스탯이 영구 합산됩니다(외형 도감에서 확인).
- **미니맵**: 구역 입장 시 지형(땅·길·물가·나무·바위·보스 제단)을 오프스크린 캔버스에 한 번 그리고, 매 프레임 플레이어·NPC·포탈·상자·몬스터 핀만 덧그립니다.
- **반응형 하단 UI**: `clamp()`·flex로 360px·390px·태블릿·PC에서 잘리지 않고 배치됩니다.

## 2단계 개편 — 아바타 · 졸업식 인트로 · 전투 연출 · 스킬북

- **아바타 4종**: 시작 화면에서 남학생 A(네이비)·여학생 A(네이비·긴 머리)·남학생 B(베이지 후드)·여학생 B(단발·리본) 중 고릅니다. 머리 모양·교복·리본 색이 3D 필드 캐릭터와 상단 HUD 프로필에 그대로 반영되고 저장본에 함께 기록됩니다.
- **졸업식 차원이동 인트로**: 새 모험을 시작하면 차원 포탈 일러스트(`assets/intro-portal.png`)와 함께 짧은 이야기가 재생됩니다(건너뛰기 / 모험 시작).
- **3단계 시작 가이드**: 이동 → 자동 공격 → 지도·가방·스킬 순서로 한 번만 안내하고, 완료 상태를 저장합니다.
- **전투 시선 정렬**: 사거리 안에 적이 있으면 이동 방향과 상관없이 적을 바라보며(스트레이프) 공격합니다.
- **무기 8종 연출**: 검 넓은 베기 아크 · 단검 찌르기 · 도끼 내려찍기+바닥 충격 · 둔기 충격 링+스턴 별 · 활 화살 · 석궁 볼트 · 지팡이/마법책 에너지탄. 흰색 히트 플래시·짧은 넉백·치명타 카메라 진동이 들어갑니다.
- **어그로 복귀**: 몬스터가 스폰 지점에서 15유닛 넘게 벗어나면 '복귀 중' 상태로 돌아가며 체력을 회복합니다. 보스·중간보스도 어그로 범위를 벗어나면 제자리를 지킵니다.
- **탱커 어그로**: 탱커 동료가 동행하면 주변 몬스터의 어그로를 대신 끌고(도발), 쓰러지면 잠시 뒤 일어납니다.
- **스킬북**: 구역 보스(중간보스는 확률)가 스킬북을 떨어뜨리고, 가방 → 스킬북에서 배워 최대 4칸 슬롯에 장착합니다. 자동 사용 토글과 직접 발동을 모두 지원합니다. 파이어볼·아이스볼트·파이어월·검기 날리기·회전 베기·멀티샷·관통 사격·단일 힐·단체 힐·독 해제 10종이며, 힐러 동료도 배운 힐 스킬을 전투 AI로 시전합니다.
- **밸런스 편집은 관리자 전용**: 설정의 무기·아이템·몬스터 수치 편집은 관리자 계정 또는 설정 → 계정의 관리자 코드로만 열립니다. 게스트·일반 계정은 읽기 전용 안내만 보입니다.
